# 小红书舆情监控助手

一个面向品牌舆情监控的 Chrome Manifest V3 扩展与 Windows 本地 Bridge。扩展读取当前小红书页面已加载的 DOM，采集帖子、评论、图片和视频，并幂等写入本地 UTF-8 CSV 与 SQLite。

公开版版本：`0.34.21`（扩展 0.34.20 / Bridge 0.34.21）

## 0.34.21 Excel 导出 IP 属地

- Excel 成组导出的“筛选评论”“需要控制_high”“中等需要控制”末尾新增“IP 属地”，保留原有列顺序、分组、筛选和标色。
- 使用每条评论自身已采集的属地；缺失留空，不以一级评论或原帖属地代填。原始筛选数据仍保留全部字段；CSV 仍按当前显示字段导出。
- 仅更新 Bridge 至 0.34.21，扩展保持 0.34.20；重启 Bridge 后重新导出即可，不修改业务数据。

- 图片区域滚动到可见位置后自动加载，沿用三请求并发限制；无图自动收起空白区域，读取或归属异常仍显示提示。
- 扩展更新为 0.34.20，Bridge 保持 0.34.18；重新加载扩展并刷新数据总览生效，不修改业务数据。

- 素材目录变更、目录缺失或未恢复检查点会明确报错，不把不完整发布当作成功。素材目录迁移仍使用采集/迁移流程。

## 0.34.17 外部 Agent 分类写入

- 外部分析分类策略升级为 `classificationPolicyVersion=2`：是、否、待复核均要求填写类型和子类型；历史列名保持不变，非差评使用有依据的内容分类，信息不足明确说明待复核原因。

- 本次更新 Bridge 与 CLI/交接文档，扩展保持 0.34.16，无需因本规则变更重新加载扩展。

## 0.34.16 无限滚动性能优化

- 普通表格首批查询建立独立只读 SQLite 浏览快照；后续分页复用同一副本，不再逐页扫描全库/CSV/素材指纹，也不等待后台采集写入锁，并复用字段目录和总数。
- 页面标注“浏览快照，更新数据查看最新”。后台采集/分析不会让已加载页和后续页混用不同版本；点击更新数据后读取最新记录。
- 浏览副本仅用于非语义表格分页，不替代详情、筛选选项、CSV/Excel 导出和删除的实时一致性校验。旧 Bridge 自动使用原查询方式。
- 缓存最多 3 个副本、合计 256 MiB，空闲 10 分钟或最长 30 分钟失效；超出容量时回退严格查询。失效后使用现有单次重校验恢复机制；正常退出时清理临时副本。
- 提前 1200–2400px 检查续载，保持单请求串行、错误停止自动重试和筛选草稿保护。
- 普通追加只处理新行的固定列和排列；没有选中记录或页内查找时，跳过对全部旧行的重复遍历。选择、查找、列宽变化仍走完整更新路径。
- 生效需要更新 Bridge 并重新加载扩展，再重新打开数据总览。

## 0.34.15 修复

- 触底加载使用合并调度；请求完成、窗口尺寸变化后重新检查，修复忙时漏加载及宽表滚动不触发。失败后停止自动重试，保留点击重试。
- 查询快照变化时尝试一次完整重校验，并在相同新快照下重读已加载页后整体替换，保留可见记录位置；不拼接新旧快照。
- 校验失败、持续变化、正在编辑筛选、已勾选记录或打开详情时保留原表格，继续使用手动更新保护；不放宽删除和导出校验。
- 此次只更新扩展，Bridge 保持 0.34.14，无需重启 Bridge。重新加载扩展并重新打开数据总览生效。

## 公开版说明

- 仓库不包含任何具体品牌名称、产品词、账号词、本机目录、Cookie、API Key 或业务数据。
- 首次安装后，请在本机配置自己的品牌词库；私有词库与运行数据均被 `.gitignore` 排除。
- 所有采集结果默认只保存在本机，Bridge 仅监听 `127.0.0.1:17881`。
- 扩展不申请 Cookie、`webRequest` 等权限，也不调用小红书隐藏接口。

## 主要功能

- 当前页面帖子核对与增量扫描。
- 帖子正文、一级/二级评论、图片与视频素材采集。
- CSV / SQLite 幂等写入、严格按笔记 ID 去重。
- 已拉取帖子评论增量同步与全库巡检。
- 数据体检、同步变更中心、重点帖子观察名单与近 7 天周报。
- 可选 DeepSeek：品牌相关性判断、正文与评论总结、评论回复建议。
- 侧边栏与详情页磁吸 Process 面板。

## 环境要求

## 直接 Clone 与安装

```powershell
git clone https://github.com/TianLongLuo/xhs-monitor-assistant.git
cd xhs-monitor-assistant
pip install -r bridge/requirements.txt
```

1. 打开 `chrome://extensions` 并启用“开发者模式”。
2. 点击“加载已解压的扩展程序”，选择仓库中的 `extension` 目录。
3. 双击 `setup.cmd`，按向导完成 Native Messaging 注册。
4. 回到扩展管理页点击“重新加载”，然后刷新已打开的小红书页面。

详细安装与故障排查见 [使用说明.md](使用说明.md)。

## 配置品牌词库

安装向导会根据示例在本机生成：

```text
bridge/data/relevance_keywords.json
```

示例格式：

```json
{
  "brand": ["品牌名", "品牌别名"],
  "products": ["产品名 A", "产品名 B"],
  "accounts": ["官方账号名"]
}
```

也可以编辑 `extension/relevance.js` 中的公开占位词，或通过本地 Bridge 维护私有词库。

## 手动安装 Native Host

```powershell
powershell -ExecutionPolicy Bypass -File bridge/build_native_host.ps1
powershell -ExecutionPolicy Bypass -File bridge/install_native_host.ps1 -ExtensionId "你的32位插件ID"
```

如需导入已有笔记 CSV：

```powershell
powershell -ExecutionPolicy Bypass -File bridge/install_native_host.ps1 \
  -ExtensionId "你的32位插件ID" \
  -SeedCsv "D:\path\to\小红书_笔记总表.csv"
```

评论 CSV 会在同目录自动创建。旧版 `-SeedXlsx` 可用于一次性迁移。

## v0.25.4：同步状态全存储一致性

- 每次单帖拉取、评论核对和批量同步都会同步帖子与评论的 `存在/已删除` 状态，并在成功前校验 CSV、SQLite、`note.json`、`comments.json` 与正文快照。
- 只有已展开全部回复、滚动到底并稳定至少两轮的可信完整评论快照，才会把消失评论软标记为 `已删除`；零评论还必须识别到页面明确空态。部分或失败快照继续保留历史状态。
- 同步前创建 CSV、SQLite 与受管素材持久检查点；任一下载、字段或状态校验失败时整体回滚，包括新增或改写的图片、视频和快照。进程异常退出后会在下次启动恢复；若检测到外部 CSV 修改则保留冲突副本并停止覆盖。
- 评论 CSV 新增 `评论用户主页url`，并修复话题逐字符展开、中文评论层级、父评论保留及跨帖子评论 ID 冲突。
- 数据体检新增帖子/评论字段漂移、素材快照字段校验及评论 ID 别名/逻辑重复候选；候选只提示审计，不会按文本自动合并。安全修复会规范话题、层级、关联链接、素材索引并重新生成快照。

### 数据总览 0.34.9：行状态与筛选导出

- 已删除记录淡粉底，已发布的语义差评淡绿底，同时命中时粉底＋绿边。所属帖已删除的评论也标粉；旧 AI 负面标记、访问待复核不等同于这两种状态。
- 默认 Excel 成组导出：左侧一级评论上下文合并，右侧逐条筛选结果；附 high/medium 子表、统计摘要、分帖汇总和全部原始字段。只导出当前筛选命中的记录，不受已加载页数或勾选行数影响，也不擅自额外限定为未删除差评。
- 一级评论未命中筛选时仍可作为关联上下文出现，不额外增加筛选条数；父链缺失、循环、跨帖时明确标记待核验。

- 导出时冻结筛选条件并核对快照、页数和记录数，校验失败不生成部分文件。Excel 单元格超长或文件超过浏览器传输上限时明确报错，可选 CSV。
- Excel 功能需要 0.34.9 Bridge；升级后重新加载扩展并重新打开数据总览。

### 同步优化 0.34.14：批内复用与有界预读

- 批量访问状态写入及素材刷新全部完成后，才从磁盘读取两张 CSV，建立仅限本批次、当前线程的校验索引。逐帖 SQLite、素材文件、字段值、重复 ID、跨帖 ID、删除状态与哈希校验照常执行。单帖接口不使用批缓存。
- CSV 解析次数由每批 `2N` 次降为 `2` 次，另外保留批末两次流式摘要复读。每次使用前检查路径/文件身份、纳秒时间与大小，退出时重验内容摘要；发现外部改动或读失败即失败，进入原有回滚/冲突保护流程，不回退到旧缓存。
- 提交阶段复用紧邻产生的标准化评论，移除一次重复标准化；公开预览仍自行验证和标准化，提交仍在锁内读取当前数据库重新比较，不采用旧预览结论或客户端“已验证”标志。
- 同一个后台标签页读取下一帖时，可并行完成当前帖的本地提交。最多一个下一帖快照，快照完成读取后深拷贝；读取彼此串行、提交彼此串行。保留 420ms 翻帖间隔及全部采集等待、重试、完整性证据。取消会等待正在提交的写入收尾，丢弃尚未提交的预读，读任务收尾后才关闭标签页。
- 迟到的上一帖进度消息由后台及页面双重检查，不重建上一帖面板。批次绑定开始时的 Bridge 地址，配置变更后不向新的地址提交这批数据。
- 无变化的帖子仍执行写入与全存储一致性校验。部分读取仍保留历史评论，不提升为完整状态；原有失败记录、重试、提醒偏好、状态批写及周报流程保留。
- 以上是减少重复工作和重叠等待，不承诺固定的整批提速比例。实际耗时仍受页面加载、评论量、素材与磁盘状态影响。应用新后端需更新并重启 Bridge；已有同步进行中时不要重启。扩展重新加载后刷新小红书页面。
