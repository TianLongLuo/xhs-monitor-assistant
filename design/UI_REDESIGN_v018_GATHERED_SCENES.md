# v0.18.0 UI：Gathered Scenes Evidence Field

## 设计命题

把插件从“数据后台”转成一张安静、可信的舆情证据桌：真实帖子素材是事实锚点，操作与状态像一根朱砂线穿过纸面，用户只需看清当前帖子、是否已收录、相关性与下一步动作。

## 来自 scenes-gathered-zine-v1-3 的转译

- **真实素材锚点**：当前详情优先显示帖子首张真实图片，不用装饰图代替事实。
- **宽松纸面**：暖灰纸色、低对比纤维纹理和主动留白，降低高密度任务的视觉负担。
- **单一结构色**：朱砂红只用于关键动作、活动状态与证据路径，不作为大面积装饰。
- **撕边证据缝**：详情卡与 Process 以纤维/撕边线分隔“网页证据”和“本地处理”。
- **场景聚合而非拼贴**：图片、标题、状态、指标和队列保持清晰层级，不加入无功能的贴纸元素。
- **字体角色**：衬线体承载帖子标题，无衬线体承载正文，等宽体承载 ID、状态和计数。

## 关键交互

1. 当前帖子卡以真实首图 + 标题 + 拉取/相关状态作为第一视觉层。
2. 主动作“拉取到 Excel”使用朱砂色；已有数据与成功状态使用墨绿。
3. 详情 Process 磁吸在帖子右侧，以纸面证据流依次展示正文、评论、素材和 Excel / SQLite。
4. 320px 侧边栏保持零横向溢出；隐藏首图后详情正文自动占满整行。
5. 悬浮球缩小后保留朱砂活动信号，展开后回到同一视觉系统。

## 可访问性与性能

- 交互元素保留 `:focus-visible` 高对比轮廓。
- 颜色之外始终配有文字状态。
- 纸张纹理由轻量内联 SVG/CSS 生成，不新增网络字体或图片请求。
- 尊重 `prefers-reduced-motion`；滚动列表和 Process 字段不使用持续装饰动画。
