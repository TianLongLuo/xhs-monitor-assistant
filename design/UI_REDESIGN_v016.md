# ORIGANI Radar UI v0.16

## 设计方向
- **主题**：精密护肤实验仪器，而不是通用数据后台。
- **颜色**：深桉绿 `#123B32`、矿物玉 `#2E7D68`、香槟金 `#D6A84B`、瓷白 `#F7F8F5`、石墨 `#17211E`、薄雾 `#E7EFEA`。
- **签名元素**：Process 与侧边栏共用一条“信号轨”，用填充高度表达扫描/拉取进度。
- **信息层级**：当前帖子 → 拉取状态 → 五步流程 → 字段/评论 → 输出文件。

## 验证循环
采用 `android-cli-ui-automation-skill` 的方法论迁移：打开 → 观察 DOM/截图 → 修改 → 重新观察。WebView/扩展界面优先截图验证，交互后重新获取状态，避免依赖过期坐标或旧 DOM。
